# История версий JustView

## 1.3.2 - 2026-11-23

- Нижняя панель gif: счётчик кадров («145 / 248») больше не налезает на шкалу, место под подписи слева и справа теперь меряется по тексту
- В заголовке окна только «JustView», без имени файла
- Автообновление с GitHub остаётся только у отдельного JustView: копия, вшитая в Instant Replay, GitHub не проверяет (её обновляет Instant Replay)

## 1.3.1 - 2026-11-23

- Исправлено удаление: «Не удалось удалить: код ошибки 124». Корзина не принимала путь расширенного вида (с префиксом из `\\?\`, его даёт канонизация пути), теперь префикс снимается и слэши приводятся к обычным. Добавлены тесты

## 1.3.0 - 2026-11-23

- Кнопка «Удалить» (корзина) в нижней панели видео: можно сразу после открытия клипа удалить его.
  Перед удалением показывается подтверждение, файл уходит в Корзину

## 1.2.0 - 2026-11-22

- Выбор языка при первом запуске: русский, English, українська. Сменить можно в справке (F1)
- Весь интерфейс переведён на английский и украинский
- Проверка обновлений на GitHub (не чаще раза в сутки): карточка «Доступна JustView X»
  с кнопками «Обновить», «Позже» и «Пропустить». «Обновить» скачивает новую версию,
  заменяет exe и перезапускает JustView с тем же файлом
- В текстах интерфейса короткие тире вместо длинных и нет точек в конце фраз

## 1.1.0 - 2026-11-22

- Выбор звуковой дорожки в видео и аудио с несколькими дорожками: кнопка слева от скорости
  с меню всех дорожек, клавиша A - следующая дорожка. Позиция, пауза и скорость сохраняются
- Понятные имена дорожек: «Общий звук (игра + микрофон)», «Звук системы», «Микрофон»
  (клипы Instant Replay, OBS), иначе название или язык из файла
- По умолчанию играет дорожка, отмеченная в файле как основная
- В «Сведениях» - список дорожек

## 1.0.1 - 2026-11-21

Исправления по результатам первого тестирования

- PDF: документ загружается из памяти - исправлена ошибка открытия
- Сведения: значения выровнены по левому краю, ссылки - по общей линии
- SVG вписывается в окно с увеличением (векторная графика не теряет чёткость)
- Аудио: панель управления больше не прячется - кроме неё на экране ничего нет
- GIF: слева номер кадра, справа длительность анимации
- Справка: исправлен неотображаемый символ

## 1.0.0 - 2026-11-21

Первая версия

- Просмотр изображений: JPEG, PNG, WebP, GIF, BMP, TIFF, ICO, TGA, DDS, HDR, EXR, QOI, PNM, SVG
  (встроенные декодеры), HEIC/HEIF, AVIF, JPEG XL, JPEG 2000, PSD, RAW-файлы камер и сотни других
  через кодеки Windows (WIC) и FFmpeg; превью Проводника для остальных файлов
- Анимации GIF / APNG / WebP с паузой, перемоткой и покадровым шагом
- Видео и аудио (любые форматы FFmpeg): перемотка, громкость, повтор, покадровый шаг,
  скорость 0,25-3× с сохранением высоты звука; волна для аудио, обложки альбомов
- PDF через встроенный движок Windows, текстовые файлы с нумерацией строк
- Масштаб колесом у курсора, перетаскивание, поворот, полноэкранный режим, сведения и EXIF,
  копирование, удаление в Корзину, листание папки в порядке Проводника, предзагрузка соседних файлов
- Регистрация в Проводнике («Открыть с помощью» и «Приложения по умолчанию»)
- Собственная иконка (видоискатель с точкой фокуса), дизайн по DESIGN.md
