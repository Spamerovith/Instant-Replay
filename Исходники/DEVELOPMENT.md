# Instant Replay - заметки для разработки

Нативное Windows-приложение на Rust: аналог NVIDIA Instant Replay + обычная запись экрана.
Текущая версия: **1.1.0** (единственный источник - `Исходники/Cargo.toml`).

## Структура

| Путь | Что там |
| --- | --- |
| `CLAUDE.md` | Правила проекта: обязательное повышение версии (SemVer) при каждом изменении |
| `Instant Replay/Instant Replay.exe` | Готовый релиз (≈5,4 МБ, без внешних DLL, статическая CRT) |
| `Исходники/` | Весь исходный код (Cargo-проект) |
| `Исходники/DESIGN.md` | Дизайн-система: цвета, шрифты, отступы, размеры, анимации |
| `Исходники/CHANGELOG.md` | История версий |
| `Исходники/build-release.ps1` | Тесты + release-сборка + копирование exe в `Instant Replay/` |
| `Исходники/.cargo/config.toml` | Кэш сборки на `D:/cargo-target/instant-replay` (диск E: почти заполнен), статическая CRT |

## Сборка

```powershell
cd "Исходники"; powershell -ExecutionPolicy Bypass -File .\build-release.ps1
```

Требуется Rust (stable, MSVC) и Windows SDK (`rc.exe` - для иконки и версии в exe).
Не переносить `target` обратно на E: - там нет места.

## Возможности

- **Instant Replay** - кольцевой буфер сжатого видео в ОЗУ (15 с - 20 мин), сохранение по хоткею
  без остановки записи, обрезка по ключевым кадрам (GOP = 2 с).
- **Запись** экрана или окна, потоково на диск.
- **Захват** - Windows Graphics Capture (монитор/окно, курсор вкл/выкл, без жёлтой рамки);
  при ресайзе окна - масштабирование с сохранением пропорций (леттербокс), при сворачивании -
  остаётся последний кадр.
- **Кодирование на GPU** через Media Foundation: NVIDIA NVENC / AMD / Intel; H.264, HEVC, AV1;
  CBR / VBR / CQP, пресеты; 30-240 к/с; до 8K (H.264 до 4096 по ширине); цвет BT.709 limited.
  Без B-кадров. Фолбэк: другой кодек → H.264 → программный H.264.
- **Звук** - системный (WASAPI loopback) + микрофон, общая шкала времени QPC с видео,
  раздельные дорожки (1 - микс, 2 - система, 3 - микрофон), громкость 0-200 %, AAC 128-192.
- **MP4** - собственный мультиплексор: faststart для повторов, 64-битные таблицы, edit lists.
- **Интерфейс** - egui, тёмная тема; трей с тёмным меню; автозапуск (`--tray`); уведомление
  поверх игры (Direct2D, исключено из захвата) + звуковой сигнал.
- **Оверлей (1.1.0)** - по Ctrl+Alt+Z главное окно превращается в панель справа на мониторе
  с игрой: галерея последних клипов, запись, мгновенный повтор + «Сохранить», микрофон, звук
  системы. Закрытие: то же сочетание, Esc, ×, клик мимо. Исключён из записи.

## Горячие клавиши по умолчанию

| Действие | Сочетание |
| --- | --- |
| Сохранить повтор | Ctrl+Alt+F10 |
| Начать / остановить запись | Ctrl+Alt+F9 |
| Вкл/выкл Instant Replay | Ctrl+Alt+F8 |
| Открыть / закрыть оверлей | Ctrl+Alt+Z |

Alt+F9 / Alt+F10 / Alt+Shift+F10 / Alt+Z на этом ПК заняты NVIDIA App - поэтому Ctrl+Alt.
Любое сочетание переназначается в «Горячих клавишах» (любая клавиша, включая Num, PrtSc,
F13-F24); занятые подсвечиваются.

## Архитектура (`Исходники/src`)

| Модуль | Назначение |
| --- | --- |
| `main.rs` | Запуск, single-instance, трей, хоткеи, уведомления, режим `--selftest` |
| `engine.rs` | Оркестрация: видео-поток, аудио-поток, sink-поток (буфер + запись), watchdog и авто-перезапуск |
| `capture/` | WGC-захват, список мониторов и окон |
| `gpu.rs` | D3D11-устройство (высокопроизводительный GPU), BGRA→NV12 + масштабирование на GPU |
| `encoder/video.rs`, `encoder/aac.rs` | MF-кодеры видео (async hardware MFT) и AAC |
| `audio.rs` | WASAPI, таймлайн по QPC с заполнением тишиной, микшер |
| `replay.rs` | Кольцевой буфер пакетов |
| `media/` | Конвертация битстрима (Annex-B/OBU → MP4), avcC/hvcC/av1C, MP4-writer |
| `hotkeys.rs`, `tray.rs`, `overlay.rs`, `sound.rs`, `autostart.rs`, `icon.rs` | Системная интеграция |
| `ui/` | `app.rs` (окно + оверлей), `widgets.rs` (контролы с анимацией), `theme.rs` (токены DESIGN.md) |

Настройки: `%APPDATA%\InstantReplay\config.json` (BOM допускается), лог: `%APPDATA%\InstantReplay\log.txt`.
Клипы по умолчанию: `Видео\Instant Replay`, имена `<Источник> - Replay|Recording <дата время>.mp4`.

## Проверено (RTX 5070 Ti, 2560×1440@60)

- H.264 / HEVC / AV1 через NVENC - 0 потерянных кадров, `ffmpeg` декодирует без ошибок,
  ровные 60 к/с, BT.709, без B-кадров; 3 раздельные аудиодорожки.
- Битрейт соблюдается: CBR ≈46, VBR ≈49 Мбит/с при цели 50; CQP (качество 80) ≈36.
- CPU в фоне 0,1-1 %; утечек нет (буфер 15 с: память стабильна 360-390 МБ за 5 мин).
- Захват окна при ресайзе и сворачивании; хоткеи; оверлей открытие/закрытие, возврат в трей.

## Самопроверка без интерфейса

```powershell
& "D:\cargo-target\instant-replay\release\instant-replay.exe" --selftest "<папка>" [h264|hevc|av1] [--rc cbr|vbr|cqp] [--mic] [--window ffplay.exe]
```
Буферизует 8 с → сохраняет повтор → пишет 6 с → останавливает; итоги в логе.
`INSTANT_REPLAY_ALLOW_CAPTURE=1` - снять исключение оверлея из захвата (для скриншотов).

## Ограничения / не сделано

- Буфер только в ОЗУ: ≈800 МБ на 2 мин при 50 Мбит/с, ≈7,5 ГБ на 20 мин (оценка показывается
  в настройках). Буфер на диске пользователь решил не добавлять.
- В старом эксклюзивном полноэкранном режиме оверлей и уведомление могут не показаться
  (звуковой сигнал работает); в безрамочном/оконном - работают.
- При аварийном завершении во время обычной записи файл записи будет без заголовка moov
  (повторы не затронуты).
- В галерее оверлея нет превью-кадров (только длительность и размер).
- Не проверено в реальной игре.
- Эффект «волны» при нажатии не реализован (ограничение egui): сжатие + смена заливки.
