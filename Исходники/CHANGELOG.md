## 1.12.2

- Исправлено: после сохранения последних N секунд буфер повтора теперь тоже начинается с нуля, как после обычного сохранения


## 1.12.1

- Обновлён вшитый JustView до 1.3.2: у gif счётчик кадров больше не налезает на шкалу, в заголовке окна просмотрщика только «JustView», вшитый просмотрщик больше не предлагает обновиться с GitHub отдельно (он обновляется вместе с Instant Replay)


## 1.12.0

- Правый клик по клипу (в галерее и плитках оверлея и в «Последних клипах») теперь даёт два пункта: «Открыть расположение» (Проводник открывается на папке клипа с выделенным файлом) и «Удалить» (с подтверждением)
- Путь к файлу для Проводника берётся в кавычках, поэтому «Открыть расположение» работает и для папок с пробелами


## 1.11.0

- Папки по играм, как у NVIDIA: при сохранении повтора или записи клип кладётся в папку с названием игры внутри папки клипов (`Bionic\Bionic - Replay ….mp4`). Если записывается окно игры (профиль игры или окно в источнике), берётся его программа; если записывается весь монитор, берётся программа в переднем плане в момент сохранения, а при пустом рабочем столе папка называется «Desktop». Имя программы определяется по списку процессов, без открытия чужих процессов. Включается и выключается в «Общие - Сохранение - Папки по играм» (по умолчанию включено). Старые клипы остаются где лежали
- Галерея в оверлее и фильтр по играм находят клипы и в папках игр (на один уровень вглубь)
- Тесты на выбор папки и имени, на имена программ и на поиск клипов в папках игр


## 1.10.0

- Фильтр сверху галереи в оверлее: переключатель «Все / Повторы / Записи» и ряд кнопок с играми («Все игры», затем каждая игра или «Рабочий стол» с числом клипов, самые частые первыми; ряд прокручивается). Игра берётся из имени файла. Если под фильтр ничего не подошло, показывается «Ничего не найдено»
- Тесты на определение игры по имени файла и на фильтр


## 1.9.0

- Галерея в оверлее стала частью приложения, а не папкой в Проводнике: по клику на «Галерея» открывается страница с сеткой всех клипов (по два в ряд, с превью, длительностью и размером). Клип открывается в JustView прямо оттуда, без показа главного окна программы; правый клик удаляет клип с подтверждением, стрелка и Esc возвращают назад, значок папки открывает папку в Проводнике. Превью делаются только для видимых плиток
- Тесты прежние, поведение проверено на живом приложении


## 1.8.0

- Превью клипов: у каждого клипа в «Последних клипах» и в галерее оверлея теперь есть картинка-кадр. У повтора берётся кадр ближе к концу (там то, ради чего его сохраняли), у записи - из начала. Кадры делает вшитый FFmpeg в фоне и кэширует в `%LOCALAPPDATA%\InstantReplay\thumbs`, так что превью есть и у старых клипов, а при удалении клипа кэш чистится
- Тесты на выбор кадра, кэш превью и получение кадра из настоящего клипа


## 1.7.2

- Оверлей снова открывается сразу: в 1.7.1 он ждал отпускания Alt/Ctrl/Shift (до 0,4 с) и из-за этого появлялся с задержкой. Теперь ожидание идёт в отдельном потоке, окно показывается мгновенно, а фокус берётся после отпускания клавиш. Замер с зажатым на 0,25 с Alt: 1.7.1 открывала оверлей через ≈300 мс, 1.7.2 через ≈45 мс. Мерцания нет, как и в 1.7.1


## 1.7.1

- Оверлей больше не мерцает при открытии поверх игры: окно остаётся прозрачным, пока не нарисованы первые кадры, отключена системная анимация появления и скрытия окна, а фокус берётся после отпускания Alt/Ctrl/Shift (одинокий Alt мог на миг включать меню окна). Проверено покадровой записью экрана: раньше при открытии поверх окна игры был один промежуточный кадр, теперь окно появляется сразу целиком


## 1.7.0

- Профили игр: новая вкладка «Игры». Добавьте запущенную игру, и пока у неё есть окно, программа сама записывает это окно и применяет её настройки (частота кадров, разрешение, качество, длина буфера). Когда игра закрыта, всё возвращается к общим настройкам. Во время записи профиль не переключается
- Анти-читы: программа ничего не внедряет в игры и не ставит хуки; игру находит по списку процессов (снимок системы) без открытия дескрипторов чужих процессов, захват идёт штатным Windows Graphics Capture
- Качество автобитрейта: «Компактно / Стандарт / Высокое» (в общих настройках видео и в профиле игры)
- Удаление клипа: правый клик по клипу в «Последних клипах» и в галерее оверлея, с подтверждением, файл уходит в Корзину
- Тесты на профили игр, качество автобитрейта и перемещение в Корзину


## 1.6.0

- JustView и FFmpeg теперь вшиты в сам `Instant Replay.exe`: скачал один файл с GitHub, и клипы сразу открываются в JustView и проигрываются, ничего ставить не нужно. При первом запуске (и после обновления) они распаковываются в `%LOCALAPPDATA%\InstantReplay\tools`
- Исходники JustView лежат в репозитории в `Исходники/justview/`, FFmpeg (LGPL) собирается в exe скриптом `prepare-embed.ps1`
- Если вшитых файлов нет, программа по-прежнему ищет установленные JustView и FFmpeg


## 1.5.0

- Быстрое сохранение: отдельное сочетание (по умолчанию Ctrl+Alt+F7) сохраняет только последние N секунд буфера, сам буфер при этом не очищается. Сочетание и число секунд (5 с - 5 мин) настраиваются во вкладке «Горячие клавиши». Клип начинается с ближайшего ключевого кадра, поэтому может быть до 2 секунд длиннее
- Автобитрейт (включён по умолчанию): битрейт подбирается под разрешение, частоту кадров и кодек. Для 1080p60 AV1 это около 7 Мбит/с вместо прежних 50, файлы в разы легче при той же чёткости; HEVC ≈ 10, H.264 ≈ 15 Мбит/с. Ручной битрейт доступен, если выключить автобитрейт
- Закрытие оверлея больше не выводит окно программы поверх игры: оно уходит на самый низ, даже если игра закреплена поверх всех окон
- Тесты на сканирование клипов, чтение длительности MP4, быстрое сохранение и автобитрейт

## 1.2.0 - 2026-11-22

- Встроенный плеер (движок JustView): клик по клипу в «Последних клипах» или в галерее
  оверлея открывает его прямо в окне Instant Replay. Перемотка, покадровый шаг, громкость,
  скорость 0,25-3× с сохранением высоты звука, полноэкранный режим, «Показать в папке»
- Выбор звуковой дорожки в плеере (клавиша A): общий звук, система, микрофон
- Раздельные дорожки: 1 - звук системы, 2 - микрофон, 3 - общий звук (игра + микрофон)
  Третья дорожка помечена основной, поэтому обычные плееры сразу играют общий звук
- Для плеера нужен FFmpeg (рядом с exe, в PATH или `winget install Gyan.FFmpeg`)

## 1.1.0 - 2026-11-22

## 1.0.0 - 2026-11-22

Первый выпуск

- Instant Replay: фоновый кольцевой буфер сжатого видео (15 с - 20 мин), сохранение клипа по
  горячей клавише без остановки записи; обрезка по ключевым кадрам
- Обычная запись экрана/окна с потоковой записью на диск
- Захват Windows Graphics Capture (монитор или окно, курсор вкл/выкл), без жёлтой рамки
- Аппаратное кодирование через Media Foundation: NVIDIA NVENC, AMD, Intel; H.264 / HEVC / AV1;
  CBR / VBR / CQP, пресеты, разрешение до 8K (H.264 до 4096), 30-240 к/с; цвет BT.709
- Звук: системный (WASAPI loopback) и микрофон, синхронизация по общей шкале QPC,
  раздельные дорожки (микс / система / микрофон), громкость 0-200 %, AAC 128-192 кбит/с
- Собственный MP4-мультиплексор: faststart для повторов, 64-битные таблицы, edit lists
- Трей с тёмным меню, глобальные хоткеи с назначением любых сочетаний, автозапуск,
  уведомление поверх игры (не попадает в запись) и звуковой сигнал
- Тёмный интерфейс по DESIGN.md
