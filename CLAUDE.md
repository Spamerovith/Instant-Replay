# Instant Replay — правила проекта

## Версия приложения (обязательно)

- При **каждом** изменении приложения обязательно обновляй его версию по SemVer `MAJOR.MINOR.PATCH`,
  пример: `1.0.0` → `1.0.1`.
- Какую версию ставить дальше, решай сам:
  - `PATCH` (1.0.0 → 1.0.1) — исправления ошибок, мелкие правки, полировка интерфейса;
  - `MINOR` (1.0.1 → 1.1.0) — новая функция или заметное улучшение без поломки настроек;
  - `MAJOR` (1.1.0 → 2.0.0) — несовместимые изменения (формат настроек, крупная переработка).
- Версия хранится в одном месте: `Исходники/Cargo.toml` → `[package] version`. Интерфейс
  берёт её через `env!("CARGO_PKG_VERSION")`, поэтому больше нигде её не правь вручную.
- После смены версии добавь запись в `Исходники/CHANGELOG.md`.

## Структура

- `Исходники/` — весь исходный код (Rust, Cargo-проект).
- `Instant Replay/` — только готовый релизный билд: `Instant Replay.exe` и всё, что нужно для запуска.
- Сборка релиза: `Исходники/build-release.ps1` (собирает `cargo build --release` и копирует exe в `Instant Replay/`).

## Дизайн

- Все значения интерфейса (цвета, шрифты, отступы, радиусы, размеры, анимации) берутся из
  `Исходники/DESIGN.md` и `Исходники/src/ui/theme.rs`. Держи их синхронными.

## Релиз на GitHub

- Релиз на GitHub обновляй **только после тестов**: сначала `cargo test` и проверка изменённого в работе
  (по возможности на собранном exe), и лишь потом коммит, тег `vX.Y.Z` и `gh release`.
- В релизе два файла: `Instant-Replay-X.Y.Z-windows-x64.zip` и отдельный `InstantReplay.exe`
  (его скачивает встроенное обновление).
- Текст релиза: одни и те же пункты изменений, просто переведённые на английский, русский и украинский
  (три блока с одинаковым содержанием), без отдельных «пересказов» и разных формулировок по языкам.
  Ссылку на скачивание и строку про `InstantReplay.exe` для обновления можно оставить.

## JustView и FFmpeg внутри exe

- `Instant Replay.exe` один: JustView (просмотрщик клипов) и FFmpeg вшиты в него и при первом запуске
  распаковываются в `%LOCALAPPDATA%\InstantReplay\tools`. Для пользователя ничего ставить не нужно.
- Исходники JustView лежат в `Исходники/justview/` (копия проекта `E:\Claude\Приложения для ПК\JustView\Исходники`).
  **Любое изменение JustView делай в обоих местах:** в отдельном проекте JustView (версия, CHANGELOG,
  его `build.ps1`, при необходимости его релиз на GitHub) и в копии `Исходники/justview/` - просто
  копируй изменения. Потом пересобери Instant Replay (`build-release.ps1`), чтобы в exe попал новый JustView.
- FFmpeg - LGPL shared сборка BtbN, кэш в `D:/cargo-target/ffmpeg-cache` (скачивается один раз
  скриптом `Исходники/prepare-embed.ps1`). Упакованные файлы лежат в `Исходники/embed/` (в git не
  попадают); без них (`cargo test`) приложение ищет установленные JustView и FFmpeg.
- Версию Instant Replay повышай и при обновлении вшитого JustView.
